# Arcading (Endless Jumper 2D)

A prototype of an endless 2D platformer built in Unity. The player jumps upward across platforms while a live altimeter tracks the height reached.

<img width="885" height="496" alt="1284" src="https://github.com/user-attachments/assets/71fb1589-3fd3-4221-97a1-d3b36c635bba" />

## Features
- Endless upward platform generation
- Player controls built with Unity's new Input System
- Automatic cleanup: platforms that fall below the camera's lower bound are destroyed
- Real-time height counter (Altimeter) in the UI
